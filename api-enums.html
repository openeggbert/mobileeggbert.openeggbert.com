ButtonGlyph — UI Buttons

39 named buttons dispatched by Game1. Groups by screen:

Main Menu (Init)

  • InitGamerA/B/C — gamer slot selection
  • InitSetup — open settings
  • InitPlay — start game
  • InitBuy — purchase full game
  • InitRanking — show high scores

Pause Menu

  • PauseMenu — return to main menu
  • PauseBack — close pause
  • PauseSetup — settings from pause
  • PauseRestart — restart level
  • PauseContinue — resume

In-Game HUD

  • PlayPause — open pause
  • PlayJump — jump (touch)
  • PlayAction — fire/action (touch)
  • PlayDown — look-down (touch)

Settings

  • SetupSounds / SetupJump / SetupZoom / SetupAccel / SetupReset / SetupReturn

Cheat Grid

  • Cheat11/12/21/22/31/32 — 3×2 unlock grid
  • Cheat1–Cheat9 — 9 cheat action buttons
